# Tax Dashboard

## Project Overview
This project is a comprehensive tax dashboard that allows users to visualize tax data effectively. It integrates data scraping from the SARS website, data management, and a user-friendly web interface.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/samhaasbroek78-dev/dashboard.git
   cd dashboard
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python src/main.py
   ```
4. Access the application at `http://localhost:5000`.
